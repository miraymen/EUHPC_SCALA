# ScaLa: Can Generative Video Replace Motion Capture?

Supplementary website for the ScaLa proposal (Scaling Laws and a Foundation Model for Human Motion) to the EuroHPC AI
Factories Access Call for Science, target system JUPITER Booster. Imperial College London.

Open `index.html` in a browser. The page is one self-contained file (font, styles and scripts inlined, no network
requests); the animations are in `website_content/videos/`.

The animations explain the proposal. Every number in them is quoted from the proposal; curves and bars marked schematic
show what the project measures, not results.
